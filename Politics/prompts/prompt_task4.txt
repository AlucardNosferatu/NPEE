考研政治帽子题逻辑拆解与结构化JSON生成任务流程
 
一、用户准备材料（每道题独立整理）
 
需提供单题对应的以下内容：
 
1. 题目基础信息：题干、选项列表、正确答案、你的答题记录（漏选/错选的选项）；
2. 你的错误答题逻辑：1-2句话说明漏选/错选的核心理由（如“漏选A，认为发展繁荣仅依赖自身”）；
3. 补充材料（可选）：题目解析（如有）。
 
二、AI执行步骤
 
1. 识别用户提供的题目材料与错误答题逻辑；
2. 基于“五等逻辑分级标准”（由用户单独提供）匹配题目对应的逻辑等级；
3. 拆解题目逻辑链（如从题干关键词匹配政治治理框架推导答案维度）；
4. 针对用户错误答题逻辑，输出逻辑矫正说明；
5. 按以下固定JSON格式生成结构化数据。
 
三、固定JSON格式规范（必填字段+内容要求）
 
json
  
{
  "question_id": "【字符串，必填，如“62”，标记题目唯一标识】",
  "question_type": "【字符串，必填，如“多选题”“单选题”，标记题目类型】",
  "stem": "【字符串，必填，完整题干内容】",
  "options": "【对象，必填，键为选项标识（如“A”“B”），值为选项完整内容】",
  "correct_answer": "【数组，必填，元素为正确选项标识（如[\"A\",\"B\"]）】",
  "user_answer": "【数组，必填，元素为你的答题选项标识（如[\"C\",\"D\"]）】",
  "logic_level": "【字符串，必填，匹配的逻辑等级（如“一等（填空级·无中生有）”）】",
  "logic_chain": "【数组，必填，元素为字符串，拆解该题的核心逻辑推导过程】",
  "wrong_logic_correction": "【数组，必填，元素为字符串，针对你的错误答题逻辑的矫正说明】",
  "memory_tip": "【字符串，必填，该题的记忆简化提示】"
}
 
 
字段说明示例
 
字段名 类型 必填 内容要求示例 
question_id 字符串 是 "62" 
question_type 字符串 是 "多选题" 
stem 字符串 是 "2025年4月中央周边工作会议指出..." 
options 对象 是 {"A":"实现发展繁荣的重要基础"} 
correct_answer 字符串数组 是 ["A","B","C","D"] 
user_answer 字符串数组 是 ["C","D"] 
logic_level 字符串 是 "一等（填空级·无中生有）" 
logic_chain 字符串数组 是 ["题干关键词匹配国家治理框架..."] 
wrong_logic_correction 字符串数组 是 ["漏选A：混淆重要基础与核心基础..."] 
memory_tip 字符串 是 "周边工作对应发展、安全等4个维度..."
