1. 任务本质：你将作为我的“智能处理助手”，手动地、逐个单元格地分析一份考研政治笔记Excel文件（“待处理”工作表），将其中适合复习的具体知识点转化为填空题。
2. 处理原则：
- 手动执行：完全依赖你的语义理解能力进行分析、判断和标记，不使用任何代码或脚本进行批量操作。
- 逐单元处理：每个单元格独立分析，内容不与其他单元格拼接。
- 精准标记：仅用  ###  标记出需要复习者填写的具体考点（如核心概念、关键参数、重要事件、主要步骤、核心规则等），知识点标题一律不标记。
- 必加提示：在  ###  标记的考点之后，必须紧跟如  （填写核心概念） 、 （填写事件名称）  等明确的答题提示，指导复习方向。
- 背景适配：结合考研政治学科特点，确保标记的考点具有复习价值，避免框选无实际意义的词汇或过长的段落。
3. 输入与输出：
- 输入：我下次将提供的Excel文件。你将从我指定的  B2  单元格开始，按顺序查看“待处理”工作表。
- 输出：你将为我整理一个规范的JSON文件。其  replace  数组中的每个对象，对应一个你判断为需要且已处理的单元格，包含其原始内容 ( old )、标记并添加提示后的新内容 ( new )、工作表名 ( sheet_name ) 和单元格地址 ( cell )。
4. 筛选标准：
- 处理：包含具体、可填写考点的句子或短语。
- 跳过：句尾含有  ### ###  的标题行、纯知识点标题、无具体考点或缺乏答题上下文的单元格。这些不会出现在最终的JSON中。
- 特例：对于内容极短（分词后≤2个词）的单元格，允许整体作为考点框选，但仍需添加提示。
5. 质量核心：确保每个填空（ ###  标记处）都具有明确的考察意图，并通过“提示+剩余文本”为复习者提供有效的答题线索，保持原句逻辑。
6. 格式示例（内容无关）：
{
  "replace": [
    {
      "old": "考察对象：端到端（传输层）",
      "new": "考察对象：###端到端（传输层）###",
      "sheet_name": "20251107",
      "cell": "C12"
    },
    {
      "old": "有效载荷：应用层数据",
      "new": "有效载荷：###应用层数据###",
      "sheet_name": "20251107",
      "cell": "C13"
    }
  ]
}
