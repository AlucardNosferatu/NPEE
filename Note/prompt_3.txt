# **考研知识点填空题转墨墨记忆卡选择题 - 任务说明（最新版）**

## **一、核心任务**
将用户提供的考研填空题知识点文本（数学二/408科目），批量转换为格式规范、选项合理、可直接导入墨墨记忆卡的**选择题（含多选题）**。每个输出必须是一个独立、完整的记忆卡条目。

## **二、输入格式**
用户输入为多条用「###」标记的填空题文本，每条之间可能有空行或缩进，但核心结构为：
`知识点描述###答案###（可能有的注释）`
**注意**：答案被包裹在「###」内，注释可有可无。

## **三、处理逻辑**
1.  **提取题干**：将「###答案###」替换为“______”，形成完整的疑问句。**务必确保题干完整、语义清晰**，即使同一知识点的不同侧面也要分别生成独立题干。
2.  **提取正确答案**：「###」内的内容即为正确答案。
3.  **生成干扰项**：基于该考点，生成**3个具有考研迷惑性**的错误选项。干扰项应与正确答案属于同一类别（如都是术语、数字、短语等）。
4.  **题型判断**：
    *   如果题干明确指向**单个答案**（如“是______？”“值为______？”），生成**单选题**。
    *   如果题干明确指向**多个并列要点**（如“排除哪些______？”“包括哪些______？”），或正确答案本身是**由多个并列部分组成的短语**，则生成**多选题**。

## **四、输出格式（必须严格遵守）**
### **核心要求**
**每道题必须独立、完整地包裹在一个单独的 \`\`\`plaintext\`\`\` 代码块中。严禁将多道题合并在同一个代码块内。**

### **单选题标准结构**
```plaintext
[题干文本______？]

[Choice##
* 正确选项（首位随机）
- 干扰项A
- 干扰项B
- 干扰项C
]
```

### **多选题标准结构**
```plaintext
[题干文本______？]

[Choice#multi#
* 正确选项A
* 正确选项B
- 干扰项A
- 干扰项B
]
```
**注意**：多选题中，所有正确选项前用 `*`，所有错误选项前用 `-`。正确选项数量依题目而定（通常2-4个），干扰项数量补足至总选项数通常为4个。

### **格式要点**
1.  **代码块**：每道题都以 \`\`\`plaintext\`\`\` 开头和结尾。
2.  **题干**：置于代码块内第一行，以问号结束。
3.  **选项块**：
    *   单选题以 `[Choice##` 开头，多选题以 `[Choice#multi#` 开头。
    *   正确选项前用星号 `*`，干扰项前用短横线 `-`。
    *   以 `]` 结束。
4.  **选项顺序**：正确选项的位置应随机分布，不要总是放在第一个。

## **五、处理流程**
1.  **按顺序处理**：严格按用户提供的输入顺序逐条转换。
2.  **忽略非标准行**：对于明显不是填空题的行（如纯标题、说明性文字、无「###」标记的行），应直接跳过，不生成任何输出。
3.  **保持原意**：转换时不得改变知识点的原意，题干表述应准确、无歧义。
4.  **逐题输出**：一道题处理并输出完毕后，再开始下一个代码块处理下一题。

## **六、示例**
### **用户输入示例**
```
有限个无穷小的和差###一定###是无穷小。
计算子网可用地址时，默认排除###网络号###和###广播地址###。
```

### **期望输出**
```plaintext
有限个无穷小的和差______是无穷小？

[Choice##
- 不一定
* 一定
- 可能
- 无法判定
]
```

```plaintext
计算子网可用地址时，默认排除哪些地址？

[Choice#multi#
* 网络号
* 广播地址
- 网关地址
- 组播地址
]
```

**请严格按照此说明执行任务，确保输出的每张记忆卡格式精准、内容可靠、可直接使用。**
