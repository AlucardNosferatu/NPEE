# **考研知识点填空题转墨墨记忆卡选择题 - 最新版任务说明 (整合修订版)**

## **一、核心任务**
将用户提供的考研知识点文本（数学、408科目等），批量转换为格式规范、选项合理、可直接导入墨墨记忆卡的**选择题（含多选题）**。每个输出必须是一个独立、完整的记忆卡条目，且所有题目在逻辑和表述上必须准确、严谨。

## **二、输入格式**
用户输入通常为结构化的知识点文本，可能包含：
1.  **标准填空题**：格式为 `知识点描述###答案###（可能有的注释）`。
2.  **描述性语句**：未被「###」标记，但包含重要概念、定义、性质或结论的文字。

## **三、处理与核查逻辑**

### **步骤1：识别考点与生成初稿**
*   **识别考点**：
    *   优先处理被「###」明确标记的填空点，每个被标记的答案原则上生成一道独立选择题。
    *   主动从**描述性语句**中提炼可考察的核心概念、关键词、关系（如“是”、“等于”、“称为”、“步骤包括”等之后的内容），并生成选择题。
*   **构造题干**：
    *   对于「###」标记处：将“###答案###”整体替换为“______”，形成完整的疑问句。
    *   对于描述性语句：将其改写成直接提问核心知识点的疑问句，句中用“______”替代待考察的关键词或结果。
    *   **题干表述应精炼、无歧义，直接考察知识点本质。避免在题干中直接给出答案或过多解题提示**（例如，不应在题干中写出“TCP头部20字节”）。
*   **确定正确答案**：「###」内的内容，或从描述性语句中提取的核心关键词，即为正确答案。
*   **生成干扰项**：为每个正确答案生成**3个具有考研迷惑性**的错误选项。干扰项应与正确答案属于同一类别（如都是术语、数字、公式、短语等），力求贴近常见错误理解。
*   **题型判断**：
    *   **单选题**：题干通常指向单一答案（如“是______？”“值为______？”“遵循______定理？”），或正确答案为单一概念。
    *   **多选题**：题干明确指向多个要点（如“包括哪些______？”“步骤是______？”），或正确答案本身是由顿号、并列连词连接的多个独立部分。

### **步骤2：答案合理性核查（关键步骤）**
在完成题目初稿生成后，**必须凭借自身知识和可靠的互联网信息**对以下内容进行核查：
1.  **核查对象**：题目中所涉及的**答案**（无论是从笔记中提取的，还是生成的干扰项）。
2.  **核查标准**：
    *   **合理**：答案准确无误，表述清晰，与公认的教材、定理或事实相符。→ **保留原题**。
    *   **表述不严谨**：答案在核心概念上正确，但存在**术语不标准、措辞有歧义、表述冗余或过简**等问题。→ **修正题目的表述**（如修正标准术语），使其合理。
    *   **逻辑性错误**：答案存在**事实性错误、与公认理论矛盾、或逻辑上不自洽**。→ **废弃该题目**，不在最终回复中输出。
3.  **核查目的**：确保最终输出的每一张记忆卡在内容上都是可靠的学习材料，避免传递错误知识。

## **四、输出格式（必须严格遵守）**
### **核心要求**
**每道题必须独立、完整地包裹在一个单独的 \`\`\`plaintext\`\`\` 代码块中。严禁将多道题合并在同一个代码块内。**

### **题干格式**
*   置于代码块内第一行，以问号结束。
*   直接以问题内容开始，**无需任何前缀**（如“题干：”），**首尾也不加中括号**。
*   **数学公式处理**：
    *   **不使用LaTeX代码**。
    *   使用**线性文本**清晰表述公式。例如：`e^(λx)`， `x^k * Q_n(x)`， `(a1*x^n + a2*x^(n-1) + ...)`。
    *   公式中的**括号统一使用英文小括号 `( )`**，避免使用中文括号或中括号 `[ ]`。

### **选项块格式**
*   **起始标记**：单选题以 `[Choice##` 开头，多选题以 `[Choice#multi#` 开头。
*   **选项标识**：
    *   正确选项前用星号 `*`。
    *   错误选项（干扰项）前用短横线 `-`。
*   **结束标记**：以 `]` 结束。
*   **选项内容**：
    *   每个选项单独一行，开头直接是 `*` 或 `-`，**后面跟一个空格**，然后接选项内容。
    *   **选项内容中若需使用中括号 `[` 或 `]`，必须进行转义，写作 `\[` 和 `\]`**。
    *   其他括号（如圆括号 `( )`）无需转义，保持原样。
    *   数学公式的表述规则与题干相同。
*   **选项顺序**：正确选项的位置应随机分布，不要总是放在第一个。

### **题解格式（可选）**
*   若题目涉及易错点、关键计算或需要特别说明，可在选项块结束后，添加一个由三个减号 `---` 构成的分隔行，然后在下方编写简短的**题解**。
*   题解应简洁，用于澄清考点、给出关键计算步骤或解释答案的合理性。
*   若无必要，则无需添加题解部分。

### **标准结构示例**
#### **单选题 (无题解)**
````plaintext
判断两个IP地址是否属于同一子网的根本依据是什么？

[Choice##
- 它们的主机号部分完全相同。
- 它们配置的子网掩码完全相同。
* 它们对应的网络前缀（即IP地址与子网掩码按位与的结果）完全相同。
- 它们属于同一个自治系统（AS）。
]
````

#### **多选题 (含题解)**
````plaintext
求矩阵A的属于特征值λ的特征向量时，需要解一个齐次线性方程组。以下哪些形式的方程组可以用于求解？（多选）

[Choice#multi#
- (A + λE)x = 0
* (A - λE)x = 0
* (λE - A)x = 0
- Ex = 0
]
---
考点：特征向量的定义是满足 (A - λE)x = 0 的非零解 x。选项B是标准形式，选项C与其等价（仅相差一个负号），因此两者均可。
````

#### **单选题 (含计算题解)**
````plaintext
若应用层数据长度为100字节，使用TCP协议传输（假设TCP头部无选项字段），则该TCP报文段的总长度是多少字节？

[Choice##
- 100
- 20
* 120
- 80
]
---
计算：TCP头部固定20字节 + 应用层数据100字节 = 120字节。
````

## **五、处理流程**
1.  **顺序处理**：严格按用户提供的输入顺序逐条分析。
2.  **深度挖掘**：不仅转换显式的填空，也主动从叙述中挖掘潜在考点。
3.  **保持原意**：转换时不得改变知识点的原意，题干表述必须准确、严谨。
4.  **核查修正**：在生成初稿后，执行“答案合理性核查”步骤，对题目进行修正或过滤。
5.  **逐题输出**：一道题处理、核查并完成最终修正后，再输出。被判定为“逻辑性错误”的题目，则跳过不输出。
