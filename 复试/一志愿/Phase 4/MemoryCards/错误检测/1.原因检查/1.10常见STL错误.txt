# 1.10 常见STL错误（考场优化版）

## 一、考场适用性评估：✅ **高度可行**

STL错误检查在考场环境中**非常适用**，原因：
1. **易于用assert检测**：大多数STL错误可转化为简单断言
2. **与算法错误可区分**：STL错误的断言模式与算法断言不同
3. **直接导致RE**：违反断言时立即触发Runtime Error

## 二、考场必须检查的STL错误

### 检查1：空容器访问 ✅
```cpp
#define CHECK_EMPTY(container) assert(!(container).empty())

// 使用示例
vector<int> vec;
queue<int> q;
stack<int> st;

// 访问前必须检查
CHECK_EMPTY(vec);  // 触发RE：容器为空
int val = vec.front();  // 安全访问
```

### 检查2：索引边界检查 ✅
```cpp
#define CHECK_INDEX(container, idx) \
    assert((idx) >= 0 && (idx) < (container).size())

// 使用示例
vector<int> vec = {1, 2, 3};
int i = 3;
CHECK_INDEX(vec, i);  // 触发RE：索引越界
vec[i] = 10;  // 安全访问
```

### 检查3：map/key存在性检查 ✅
```cpp
#define CHECK_KEY_EXISTS(map, key) \
    assert((map).find(key) != (map).end())

// 使用示例
map<string, int> word_count;
string key = "test";

// 错误：m[key]会插入默认值，m.at(key)会抛异常
// 正确：
CHECK_KEY_EXISTS(word_count, key);  // 触发RE：key不存在
int count = word_count[key];  // 安全访问
```

### 检查4：迭代器有效性检查（基本） ✅
```cpp
#define CHECK_ITER_VALID(container, iter) \
    assert((iter) != (container).end())

// 使用示例
vector<int> vec = {1, 2, 3};
auto it = find(vec.begin(), vec.end(), 4);  // 返回end()

CHECK_ITER_VALID(vec, it);  // 触发RE：无效迭代器
int val = *it;  // 安全解引用
```

## 三、考场推荐检查模式

### 模式1：安全访问包装函数
```cpp
// 考前记忆的模板函数
template<typename T>
T& safe_at(vector<T>& vec, int idx) {
    CHECK_INDEX(vec, idx);
    return vec[idx];
}

template<typename Container>
auto safe_front(Container& c) -> decltype(c.front()) {
    CHECK_EMPTY(c);
    return c.front();
}

template<typename K, typename V>
V& safe_get(map<K, V>& m, const K& key) {
    CHECK_KEY_EXISTS(m, key);
    return m[key];
}

// 考场使用
vector<int> vec = {1, 2, 3};
int val1 = safe_at(vec, 1);  // 安全
int val2 = safe_front(vec);   // 安全

map<string, int> m = {{"a", 1}};
int val3 = safe_get(m, "a");  // 安全
```

### 模式2：范围有效性检查
```cpp
#define CHECK_RANGE(container, left, right) \
    assert(0 <= (left) && (left) <= (right) && (right) < (container).size())

// 使用示例
vector<int> vec(100);
int l = 10, r = 20;
CHECK_RANGE(vec, l, r);  // 检查范围有效性
for (int i = l; i <= r; i++) {
    vec[i] = i;
}
```

## 四、考场STL使用最佳实践

### 1. 优先使用安全模式
```cpp
// 避免：可能越界的直接访问
vec[i] = value;  // 危险

// 使用：先检查后访问
CHECK_INDEX(vec, i);
vec[i] = value;  // 安全

// 或者使用安全包装
safe_at(vec, i) = value;  // 更安全
```

### 2. 避免迭代器失效
```cpp
// 考场策略：尽量使用下标而不是迭代器
vector<int> vec = {1, 2, 3};

// 错误：修改容器后使用旧迭代器
auto it = vec.begin() + 1;
vec.push_back(4);  // 可能使it失效
// *it = 10;  // 危险

// 正确：使用下标
int idx = 1;
vec.push_back(4);
CHECK_INDEX(vec, idx);  // 仍然有效
vec[idx] = 10;  // 安全
```

### 3. 算法使用前检查前提条件
```cpp
// binary_search要求有序
vector<int> vec = {3, 1, 2};
sort(vec.begin(), vec.end());  // 先排序

// 可选：检查已排序（调试用）
#if DEBUG
assert(is_sorted(vec.begin(), vec.end()));
#endif

bool found = binary_search(vec.begin(), vec.end(), 2);
```

### 4. 容器选择简化策略
```cpp
// 复杂：嵌套容器+指针（易错）
vector<map<int, vector<int*>>> complex;

// 简化：值语义+扁平设计（易调试）
struct Item {
    int key;
    vector<int> values;
};
vector<Item> simple;
```

## 六、考场实施流程

### 步骤1：编码时添加关键检查
```cpp
// 在以下位置必须添加检查：
// 1. 容器访问前（索引、front/back）
// 2. map查找前
// 3. 迭代器解引用前

vector<int> solve(const vector<int>& input) {
    // 检查输入
    CHECK_EMPTY(input);
    
    vector<int> result;
    for (int i = 0; i < input.size(); i++) {
        // 检查索引（在循环外检查一次更好）
        CHECK_INDEX(input, i);
        
        // 处理逻辑
        result.push_back(transform(input[i]));
    }
    
    return result;
}
```

### 步骤2：使用检查进行调试
```cpp
// 调试配置
#define DEBUG_STL_CHECKS 1

#if DEBUG_STL_CHECKS
    // 所有检查生效
#else
    // 所有检查禁用
#endif

// 提交策略：
// 1. 第一次提交：DEBUG_STL_CHECKS = 1
//    - 如果RE → STL使用错误
//    - 如果WA → 算法逻辑错误
// 2. 修复后提交：DEBUG_STL_CHECKS = 0
```

### 步骤3：最终提交清理
```cpp
// 提交前确保
#define DEBUG_STL_CHECKS 0

// 可选：完全移除检查代码
// 或使用条件编译排除
```

## 七、必须记忆的检查宏

```cpp
// 考前记住这5个核心检查宏
#define CHECK_EMPTY(c)      assert(!(c).empty())                    // 容器非空
#define CHECK_IDX(c, i)     assert((i) >= 0 && (i) < (c).size())    // 索引有效
#define CHECK_KEY(m, k)     assert((m).find(k) != (m).end())        // key存在
#define CHECK_ITER(c, it)   assert((it) != (c).end())               // 迭代器非end
#define CHECK_RANGE(c,l,r)  assert(0<=(l)&&(l)<=(r)&&(r)<(c).size())// 范围有效
```

## 八、常见STL错误示例与修正

### 错误1：空容器访问
```cpp
// 错误
vector<int> vec;
int val = vec.back();  // RE: 未定义行为

// 修正
CHECK_EMPTY(vec);
int val = vec.back();  // 安全
```

### 错误2：越界访问
```cpp
// 错误
vector<int> vec(10);
vec[10] = 5;  // RE: 越界

// 修正
int idx = 10;
CHECK_IDX(vec, idx);
vec[idx] = 5;  // 安全（会触发RE，但可调试）
```

### 错误3：无效map访问
```cpp
// 错误
map<string, int> m;
int val = m["nonexistent"];  // 会插入默认值，可能不是预期行为

// 修正（如果不应插入）
string key = "nonexistent";
CHECK_KEY(m, key);
int val = m[key];  // 安全（确保key存在）
```

### 错误4：无效迭代器
```cpp
// 错误
vector<int> vec = {1, 2, 3};
auto it = find(vec.begin(), vec.end(), 4);
int val = *it;  // RE: 解引用end()

// 修正
auto it = find(vec.begin(), vec.end(), 4);
CHECK_ITER(vec, it);
int val = *it;  // 安全
```

## 九、考场注意事项

### 1. 检查代价控制
```cpp
// 避免在紧密循环中频繁检查
// 在循环外检查一次，而不是每次迭代都检查

// 不好：每次迭代都检查
for (int i = 0; i < n; i++) {
    CHECK_IDX(vec, i);  // 重复检查
    // ...
}

// 好：循环外检查一次
assert(n <= vec.size());  // 一次检查
for (int i = 0; i < n; i++) {
    // 不再检查，直接访问
    vec[i] = i;
}
```

### 2. 避免嵌套检查
```cpp
// 错误：检查本身可能越界
assert(vec.size() > 0 && vec[0] == 42);  // 如果vec为空，vec[0]已越界

// 正确：分步检查
assert(!vec.empty());      // 先检查非空
assert(vec[0] == 42);      // 再访问
```

### 3. 使用标准算法前提
```cpp
// 某些算法有前提条件
vector<int> vec = {3, 1, 4, 1, 5};

// sort前：确保可比较（默认支持）
sort(vec.begin(), vec.end());

// binary_search前：必须有序
#if DEBUG
assert(is_sorted(vec.begin(), vec.end()));
#endif
bool found = binary_search(vec.begin(), vec.end(), 3);
```

## 十、总结：考场STL错误检查清单

### ✅ 必须实施的检查：
1. **空容器检查**：`front()`、`back()`、`pop()`前
2. **索引边界检查**：`operator[]`、`at()`前
3. **map键存在检查**：使用`find()`确认存在
4. **迭代器有效性**：解引用前检查不是`end()`

### 📋 考前准备：
1. **记忆5个核心检查宏**
2. **练习安全访问模式**
3. **了解常见STL陷阱**

### 🎯 考场策略：
1. **第一阶段**：编码时在关键位置添加检查
2. **第二阶段**：开启检查调试，区分STL错误和算法错误
3. **第三阶段**：关闭检查，提交最终代码

### ⚠️ 特别注意：
- 避免迭代器失效：尽量使用下标而不是迭代器
- 优先使用值语义：避免指针和复杂嵌套
- 控制检查频率：避免性能影响

通过系统化的STL错误检查，可以在考场中有效识别和修复低级错误，确保RE只由算法断言触发，提高调试效率。
