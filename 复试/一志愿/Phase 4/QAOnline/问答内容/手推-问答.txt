### 题目1（聚焦STL next_permutation - 机试排列组合高频考点）
【人肉推演】已知C++ STL的`next_permutation`函数作用：对数组按**字典序**生成下一个排列，若已是最后一个排列则返回false，数组保持降序；**要求数组初始为升序才会生成全排列**。请手动推演以下两个用例的执行结果（写出关键推演步骤+最终数组状态+函数返回值）：
- 普通用例：数组`nums = [1,2,3]`，调用1次`next_permutation(nums)`
- 边界用例：数组`nums = [3,2,1]`，调用1次`next_permutation(nums)`
**作答要求**：分别推演两个用例，步骤简洁标注核心判断点（如“是否为最后一个排列”）。

#### 预期答案
- 普通用例：
  推演步骤：[1,2,3]是升序初始态，字典序下一个排列为[1,3,2]，非最后一个排列；
  最终结果：数组变为[1,3,2]，函数返回**true**。
- 边界用例：
  推演步骤：[3,2,1]是字典序最后一个排列，调用后函数返回false，数组保持原降序；
  最终结果：数组仍为[3,2,1]，函数返回**false**。

### 题目2（聚焦STL bisect/二分查找 - 机试查找高频考点）
【人肉推演】已知Python bisect模块的`bisect_left(a, x)`函数作用：在**升序无重复数组a**中，查找元素x的插入位置，使插入后数组仍升序；若x在a中，返回其**第一个下标**；若x小于所有元素返回0，大于所有元素返回len(a)。请手动推演以下两个用例的执行结果（写出关键推演步骤+最终插入位置）：
- 普通用例：数组`a = [1,3,5,7]`，调用`bisect_left(a, 5)`
- 边界用例：数组`a = [2,4,6]`，调用`bisect_left(a, 7)`
**作答要求**：分别推演两个用例，步骤标注核心判断（如“x是否在数组中/与边界元素比较”）。

#### 预期答案
- 普通用例：
  推演步骤：升序数组a中存在5，下标为2，bisect_left返回其第一个下标；
  最终结果：插入位置为**2**。
- 边界用例：
  推演步骤：7大于数组中所有元素（最大为6），按规则返回数组长度len(a)=3；
  最终结果：插入位置为**3**。

### 题目3（聚焦余数周期性 - 离散数学+机试取模高频考点）
【人肉推演】机试中常利用余数的周期性简化计算，已知规则：对于正整数a、b，`a % b`的结果范围为`0 ≤ 结果 < b`，且连续正整数对b取模会呈现周期为b的循环。请手动推演以下两个用例的执行结果（写出关键推演步骤+最终余数）：
- 普通用例：计算`27 % 5`
- 边界用例：计算`5 % 5`、`0 % 5`（两个子边界，均需推演）
**作答要求**：标注余数计算核心规则，步骤简洁（如“找到最大倍数≤被除数”）。

#### 预期答案
- 普通用例：
  推演步骤：5的5倍=25≤27，27-25=2，结果在0-4范围内；
  最终结果：余数为**2**。
- 边界用例：
  推演步骤1（5%5）：5的1倍=5≤5，5-5=0，符合余数规则；结果为**0**；
  推演步骤2（0%5）：0除以任何正整数，余数均为0，符合规则；结果为**0**。

### 题目4（聚焦简单循环推演 - 机试数组操作高频考点）
【人肉推演】已知一段简单C++循环代码（无语法错误），功能为遍历数组修改元素，代码如下：
```c++
int nums[] = {1,2,3,4};
int n = 4;
for(int i=0; i<n-1; i++){
    nums[i] = nums[i] + nums[i+1];
}
```
请手动推演以下两个用例的执行结果（写出关键推演步骤+最终数组状态）：
- 普通用例：按上述代码执行（i<n-1）
- 边界用例：若循环条件改为`i<n`（遗漏边界，机试高频错点），重新执行
**作答要求**：按循环次数逐步标注数组变化，核心标注“循环终止条件/是否越界”。

#### 预期答案
- 普通用例（i<n-1，i=0/1/2）：
  推演步骤：
  i=0：nums[0]=1+2=3 → 数组[3,2,3,4]；
  i=1：nums[1]=2+3=5 → 数组[3,5,3,4]；
  i=2：nums[2]=3+4=7 → 数组[3,5,7,4]；
  i=3：不满足i<3，循环终止；
  最终结果：数组为**[3,5,7,4]**（无越界）。
- 边界用例（i<n，i=0/1/2/3）：
  推演步骤：
  前3次循环同普通用例，数组变为[3,5,7,4]；
  i=3：执行nums[3]=4+nums[4]，**nums[4]为数组越界地址**（机试RE错点）；
  最终结果：**数组越界（Runtime Error）**，无有效结果。
