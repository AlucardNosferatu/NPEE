## 2015.6–2016.6 个人创客工作室技术总结
## 一、核心硬件设备
1. **FDM 3D打印机**
闪铸 Flashforge Finder（红黑外壳，热床印有品牌标识），玻璃热床，支持 PLA/ABS，通过 U 盘拷贝 G-code 离线打印，不直接读取 STL。

2. **激光切割/雕刻设备**
Makeblock XY 绘图仪 V2.0 + 500mW 激光升级头，蓝色铝型材框架。

3. **辅助设备**
- DIY 桌面塑料挤丝机：PLA/ABS 废料破碎熔融，再生打印线材；
- Kinect 2.0 深度相机：实物 3D 扫描与逆向建模。

## 二、软件工具链
- 机械参数化建模：SolidWorks
- 雕刻与网格修复：ZBrush 4R7
- 激光切割矢量绘图：Inkscape 0.91（导出 SVG）
- 3D 打印切片：Cura 15.04
- 激光控制：mDraw
- 3D 扫描重建：ReconstructMe

## 三、关键技术参数与实操细节
1. **耗材与温度**
   - 主流线材直径：**1.75mm**；
   - PLA：喷头 210–220℃，热床 45–50℃；
   - ABS：喷头 230–240℃，Finder 热床能力有限，易翘边，较少使用。

2. **500mW 激光切割能力**
   - 单次无法切透 1mm 亚克力；
   - 通过**低速+多次重复走刀**，可稳定切穿 1mm 亚克力板。

3. **3D 扫描与 Mesh 处理**
   - Kinect 输出深度图+点云，ReconstructMe 自动生成 Mesh 并导出 STL；
   - ZBrush 底层为多边形网格，可直接导入 STL 进行修复、简化；
   - SolidWorks 为参数化建模，不直接编辑 Mesh，采用逆向工程：以 STL 为参考，配合 ScanTo3D 或草图映射快速重建参数化模型，不逐点重绘。

4. **环境影响**
   - 湿度：耗材吸水会导致气泡、分层、堵头，需密封+干燥剂保存；
   - 光照：紫外线使线材老化变脆，必须避光存放。

## 四、常见打印机故障与排除
1. **第一层不粘**：自动调平 → 清洁平台 → 贴美纹纸/涂胶 → 微调喷嘴高度
2. **翘边**：提高热床温度 → 前几层关风扇 → 开启裙边辅助
3. **堵头**：升温清洗 → 重新进退丝 → 细针通孔
4. **打印错位**：检查皮带张力 → 降低打印速度 → 清理导轨
5. **中途断丝**：更换新耗材 → 检查进料齿轮压力

## 五、常见打印件瑕疵及修复
1. **气泡/爆米花纹**：耗材烘干，提高喷头温度
2. **层纹粗糙**：减小切片层高，降低打印速度
3. **翘边**：热床保温，添加 Brim/Raft，平台涂胶
4. **层间分离**：提高喷头温度，前几层关闭风扇
5. **拉丝串料**：加大回抽设置，适当降温
6. **填充不实**：提高填充率，检查出丝是否顺畅

## 六、标准工作流程
1. **3D 打印**：SolidWorks/ZBrush 建模 → STL → Cura 切片 → G-code → U 盘 → 闪铸 Finder 打印
2. **激光切割**：Inkscape 绘矢量图 → SVG → mDraw → 多次重复切割 → 1mm 亚克力切穿
3. **逆向扫描**：Kinect 采集 → ReconstructMe 生成 Mesh → ZBrush 修复 → SolidWorks 逆向参数化建模
