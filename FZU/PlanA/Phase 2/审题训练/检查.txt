## 三、算法选择Checklist（二分决策树+适用条件清单）
### 1. 二分决策树（算法选择流程）
开始：面对问题P
Q1：问题是否可以通过穷举所有可能性解决，且数据规模极小（n≤15）？
├── Yes → 暴力枚举思想
└── No → Q2
Q2：问题是否可以通过"局部最优选择"得到全局最优，且选择不可撤销？
├── Yes → 贪心思想
└── No → Q3
Q3：问题是否可以分解为子问题，且子问题相互独立？
├── Yes → 分治思想
└── No → Q4
Q4：问题是否具有最优子结构和重叠子问题？
├── Yes → 动态规划思想
└── No → Q5
Q5：问题是否需要在大量可能性中搜索，且存在明确的约束条件？
├── Yes → 回溯思想（需要回退）
└── No → Q6
Q6：问题是否可以接受近似解，且需要高效算法？
├── Yes → 近似思想
└── No → Q7
Q7：问题是否对确定性算法困难，但随机化可能有效？
├── Yes → 随机化思想
└── No → 可能为NP难问题，考虑特殊算法或启发式

### 2. 各思想适用性Checklist
#### 贪心思想适用性检查清单：
1. [ ] 问题具有最优子结构
2. [ ] 具有贪心选择性质（可证明）
3. [ ] 决策不可撤销
4. [ ] 不需要比较所有历史信息

#### 动态规划思想适用性检查清单：
1. [ ] 问题具有最优子结构
2. [ ] 子问题重叠（重复计算）
3. [ ] 无后效性（当前决策不影响过去）
4. [ ] 状态空间可管理（不指数爆炸）

#### 回溯思想适用性检查清单：
1. [ ] 解空间可表示为树/图
2. [ ] 存在明确的约束条件
3. [ ] 需要找到所有解或一个解
4. [ ] 可设计有效的剪枝策略
