# 一、影像预处理（必提，最基础、最安全）
## 1. 高斯滤波
- 核心作用：**去除医学影像里的高斯噪声（CT/MRI里的颗粒状杂点）**，属于线性平滑滤波
- 你主动说：医学影像噪声大，我常用**高斯滤波**做基础去噪，保留整体结构
- 老师追问：和中值滤波区别？
  你答：高斯滤高斯噪声，中值滤椒盐噪声，医学影像一般先用高斯
- 高斯噪声是整体均匀的模糊噪点，椒盐噪声是随机出现的黑白孤立噪点。
- 高斯滤波的 “权”，就是高斯核里按高斯分布算出来的权重；滤波就是用这些权重做局部加权平均。

## 2. 中值滤波
- 核心作用：**去掉椒盐噪声（黑白杂点）**，非线性滤波，不模糊边缘
- 你主动说：针对影像里的椒盐噪声，会用**中值滤波**做降噪
- 老师追问：适用场景？
  你答：适合噪声是离散杂点的情况，保护影像边缘
- 中值滤波的中心像素，正好就是椒盐噪声所在的那个异常像素点。
- 用周围正常像素的中位数替换它，0 或 255 的噪点就直接被消除了。

## 3. 直方图均衡化
- 核心作用：**增强影像对比度**，让暗的更清、亮的更准，方便后续处理
- 你主动说：预处理最后会做**直方图均衡化**，提升医学影像的对比度
- 老师追问：目的？
  你答：让原本看不清的组织边界更明显，便于特征提取
- 直方图均衡化就是把挤成一团的灰度分布强行拉平铺满 0-255，实现自动增强对比度。

# 二、影像分割（核心技术，老师最爱问）
## 1. 阈值分割
- 核心作用：**按灰度值大小，把前景和背景分开**（最简单的分割）
- 你主动说：基础分割用**阈值分割**，通过灰度阈值区分目标区域
- 老师追问：固定阈值缺点？
  你答：对光照/灰度不均的影像效果差，适合简单场景

## 2. Canny边缘检测
- 核心作用：**提取影像里的轮廓、边界线**
- 你主动说：做组织轮廓提取时，会用**Canny边缘检测**找边界
- 老师追问：步骤？
  你答：先高斯去噪，再算梯度，非极大值抑制NMS，最后双阈值筛选
- 梯度代表了像素灰度值变化最强烈的地方，而边缘正是这种剧烈变化的位置，所以用它能精准检测边缘。
- NMS不是必须的，但做精准分割、特征提取时必须用，粗边缘会导致轮廓不准、特征计算出错。

## 3. 区域生长
- 核心作用：**从一个种子点出发，把相似灰度的区域连起来**，做目标分割
- 你主动说：针对小目标区域，用**区域生长**做精准分割
- 老师追问：关键？
  你答：选好种子点+灰度相似规则，就能把目标区域抠出来
- 阈值分割是按灰度全局一刀切，不管位置；
- 区域生长是从种子点出发，只收周围相似的，带位置约束。

# 三、影像特征提取（衔接你刚学的SVM，绝杀关联）
## 1. 灰度共生矩阵（GLCM）
- 核心作用：**提取影像的纹理特征**（粗糙/细腻、均匀/杂乱）
- 你主动说：分割后用**GLCM**提取纹理特征，用来做后续分类
- 老师追问：干嘛用？
  你答：描述影像纹理，输入给SVM做分类识别
- GLCM = 图像版二元词共现矩阵（2-gram），都是统计相邻元素的配对频率；区别只在一个是一维文本词对，一个是二维图像灰度像素对。

## 2. 灰度特征
- 核心作用：**均值、方差、熵**，最简单的统计特征
- 你主动说：基础特征会提取灰度均值、方差这类统计量
- 老师追问：作用？
  你答：快速表征影像整体灰度分布

# 四、影像配准（经典技术，显专业）
## 刚性配准
- 核心作用：**把多张影像对齐**（平移、旋转、缩放，不形变）
- 你主动说：多模态影像融合前，会做**刚性配准**实现影像对齐
- 老师追问：用途？
  你答：让不同时间/不同设备拍的影像位置统一，方便对比
- 平移、旋转、缩放、反射、剪切，全都属于仿射变换，它保证直线还是直线、平行关系不变。
- 你之前说的那几种只是仿射里最简单的子集；仿射可以做斜切变形，比单纯刚性变换能力更强。
- 再往上更 “厉害” 的是投影变换（单应性），连平行性都能改，适合大视角、透视对齐。
- SolidWorks 里关掉透视的等轴测视图，就是典型的正交投影 → 属于仿射变换，没有近大远小、平行线永远平行。

# 五、机器学习在影像中的应用（和你SVM知识强绑定，必提）
## 1. SVM 医学影像分类
- 核心作用：把提取好的GLCM/灰度特征，用SVM做二分类/多分类
- 你主动说：提取完特征后，用**SVM**做医学影像的病灶/正常区域分类
- 老师追问：核函数选啥？
  你答：非线性数据用RBF核，线性可分就用线性核
- 高斯核 = RBF 核 = 最强的非线性核，专门搞非线性问题。

## 2. 随机森林
- 核心作用：集成分类，比单SVM抗噪声，医学影像小样本常用
- 你主动说：也会用**随机森林**做影像分类，泛化性更好
- 老师追问：优势？
  你答：不容易过拟合，对噪声鲁棒
- 决策树 = 一个单独的 “小学生”，有时候会粗心犯错。
- 随机森林 = 一个由 100 个小学生组成的 “班级”，大家各自做题，最后投票选答案，准确率远高于单个小学生。
- 随机森林里的每棵树，最常用的是CART 树（二叉树，既可以分类也可以回归）
- CART 做分类时，核心就是用基尼系数（Gini）来选分裂特征。
- ID3是信息增益，也就是这一个分类下去，到每个叶子的高度越少越好。
- 但是这样分类太蠢了，ID3会找一个分类贼多但是没啥屌用的（比如学号）一分下去然后收工。
- 为了防止用信息增益选择决策因素导致决策树怠工，使用信息增益率。
- 也就是拿信息增益（类比加权平均深度）除以分裂信息（类比分支个数，是一种惩罚），防止决策树变宽扁。
- 基尼系数 = 衡量 “从分好的某一类里随机抽取并且放回，类别不一样的概率”
