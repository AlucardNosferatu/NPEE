## 二、信号畸变类核心问题
1. 信号反射
2. 振铃现象
3. 过冲（Overshoot）：信号跳变时，瞬时幅度超出目标逻辑电平上限的部分。
4. 下冲（Undershoot）：信号跳变时，瞬时幅度低于目标逻辑电平下限的部分。
5. 码间干扰（ISI）：前一个脉冲的拖尾衰减太慢，侵占了下一个码元的时间窗口，导致本该是低电平的位置被前一个信号的 “尾巴” 抬高，造成判决错误。

## 三、干扰与噪声核心问题
1. 近端串扰NEXT：干扰信号在发送端同侧被耦合到相邻线上，串扰的方向与原信号相反。
2. 远端串扰FEXT：干扰信号传到线路末端同侧被耦合到相邻线上，串扰的方向与原信号相同。
3. 容性耦合：一根线电压跳变，通过寄生电容，把相邻线的电压同步拉高 / 拉低，这个干扰顺着原信号方向走。
4. 感性耦合：原信号的电流变化会产生磁场，在相邻线上感应出反向电流，这个干扰往发送端反着走。
5. 同步开关噪声（SSN）：不小心在电源 / 地的寄生电感上，也炸出了瞬间高压，变成干扰。
6. 地弹噪声：地线的寄生电感发生了瞬间高压，导致基准偏高。
7. 共模噪声与差模噪声

## 七、答疑
1. 传输线阻抗突变就像光从空气射入水中，介质特性突变导致电磁波（电信号）部分反射、部分继续传输，这是信号完整性所有问题的物理根源。
2. 特征阻抗是传输线的分布参数阻抗，由导体几何尺寸 / 布局与介质介电常数共同决定，是电磁波在整条传输线结构中传播的等效阻抗。
3. 传输线存在固有谐振频率，由线长与信号传播速度决定，谐振时会形成驻波、阻抗剧烈突变，直接破坏信号完整性。
4. 单纯信号反射只会造成幅度叠加，不一定产生振荡；但振铃一定是反射波与传输线 / 器件的寄生 LC 谐振共同作用的结果。
5. 高频时传输线特征阻抗基本恒定，低频会因损耗明显变化，本质是分布电感、电容随频率的通阻特性在共同起作用。
6. 信号源作为可控电压源，经信号线到高阻负载时必然产生反射能量，串联端接在源头吸收反射不再反弹，并联端接则直接给反射能量开一条直通地的回路，避免其干扰信号。

## 八、信号完整性 ↔ 计算机组成 / CPU 时序（硬件底层强绑定）
1. 一句话核心：计算机所有时序逻辑（CPU 取指、数据读写、总线传输）的前提，是信号能准时、不失真到达，信号完整性直接决定 CPU / 内存 / 总线能不能跑高频、不读错数据。
2. 重点：机器人CAN总线作为控制器与舵机、电机间的I/O通信总线，长线传输引发的信号反射、波形畸变等信号完整性问题，会直接破坏总线位时序与电平采样逻辑，导致计算机控制系统的指令传输失效。
3. 重点：通过对CAN总线进行末端阻抗匹配、优化信号回流路径并抑制长线反射，修复畸变波形以保证总线位时序稳定，恢复指令采样的可靠性。
4. CPU、内存、PCIe 这些计算机核心部件，全靠时序规则工作：比如数据必须在时钟沿的建立时间 (setup)、保持时间 (hold) 内稳定到达，CPU 才会正确识别 0/1。
5. 你之前学的反射、畸变、时序偏移，会让信号迟到、变形、抖动，直接破坏 setup/hold 时序，导致 CPU 把 0 读成 1、内存丢数据、系统死机。
6. 像 DDR5、PCIe 5.0 这些高速计算机总线，频率越高对信号完整性要求越苛刻 ——计算机的性能上限，本质是被信号完整性托住的，不是单纯靠 CPU 算力。

## 九、算法 / 建模思维 ↔ 电路 / 信号完整性问题（用计算思维解硬件问题）
1. 一句话核心：把电路物理问题转化为数学模型 + 计算机算法，用仿真、优化、图论等计算思维，替代硬件盲试，精准分析 / 解决信号问题。
2. 重点：图论建模回流 / 布线：把 PCB 的信号线、地平面看成图的节点边，用最短路径、最小割算法找最优回流路径、规避串扰，和计算机网络路由思维同源。
3. 数值建模 + 仿真算法：用有限元法 (FEM)、矩量法把传输线、PCB 走线转化为数学模型，计算机模拟信号反射、串扰，相当于给电路做「数字孪生」，不用焊板子就能预判问题。
4. 优化算法做阻抗匹配：用遗传算法、梯度下降自动找最优端接电阻 / PCB 线宽，代替人工试凑，和 AI 调参、算法优化逻辑完全一致。
5. 时序调度算法：把总线信号传输看成任务调度，用动态规划校验时序裕量，保证 CPU / 总线时序合规，和操作系统任务调度逻辑相通。
