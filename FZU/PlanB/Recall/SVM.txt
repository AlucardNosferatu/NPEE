# SVM 人话版操作流程（只记步骤，不记原理）
1. 先把处理好的数据（特征）整理好，分成两类（比如左手想象、右手想象）
2. 让SVM在这些数据里找一条**最宽的分界线**，把两类尽量分开
3. 用这条分界线去判断新来的脑电数据属于哪一类
4. 最后输出分类结果（也就是识别出用户想做什么动作）

# SVM 找超平面·人话强化版（只记流程，不碰公式）
1. 先看数据在**当前维度**能不能用一条直线/平面分开
    - 能分开（线性可分）：直接找**最宽的那条分界线**就行
    - 不能分开（线性不可分）：**不硬在原维度画线**
2. 线性不可分的核心操作：**给数据升维度**
    - 原来点都在一个平面上，乱成一团分不开
    - 我们假设把这些点**“抬到三维空间里”**
    - 一抬起来，原本搅在一起的点，在高维里就自然分层、能分开了
3. 在这个**更高维度里**，再去找一个最宽的**超平面**把两类隔开
4. 实际计算时不会真去手动升维，用**核函数**直接等价实现，省算力

核函数**不是你自己算出来、推导出来的，也不是从数据里“挖”出来的**，它是**现成直接用的标准模板**，这就是它的“到手”方式。
1. **核函数是提前定义好的固定公式**
    线性、多项式、RBF高斯核，都是数学家早就写好的标准式子，**你不用自己造，直接拿来用**。
2. **实际用的时候，只做“选择”，不做“创造”**
    面对数据，你就从那三个常用核里挑一个：
    - 线性可分 → 选**线性核**
    - 非线性、乱哄哄的数据（比如脑电BCI）→ 直接选**RBF高斯核**
3. **工具/代码里直接调用**
    不管是SVM库还是BCILAB，里面都封装好了核函数，你只需要指定用哪个核，它自动帮你完成隐形升维、算超平面，不用你手写核函数。
